#  Port Scanner

A simple command-line port scanner written in python.

## Features

Scans port in definited range, using multithread technology

## Technologies

- Python 3
- socket
- ipaddress
- time
- concurent.future

## Installation

Clone the repository

```bash
git clone https://github.com/AlpachaAlikhan/port-scanner.git
```

Open the project

```bash
cd port-scanner
```

Run

```bash
python port-scanner.py
```
